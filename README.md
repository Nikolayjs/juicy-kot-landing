# Дневник тренировок — лэндинг

Статическая страница приложения «Дневник тренировок» (Android): `index.html`, `styles.css`, `script.js`, без сборки.

Публикуется через GitHub Pages из ветки `main` (корень). Ссылка на установку — константа `DOWNLOAD_URL` в начале `script.js`; пока она пустая, главная кнопка показывает «Скоро».

Исходники лэндинга живут в основном (приватном) репозитории приложения, в папке `landing/`; сюда копируются для публикации.
