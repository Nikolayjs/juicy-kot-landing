# Лэндинг «Дневник тренировок»

Статическая страница: `index.html`, `styles.css`, `script.js` — без сборки и зависимостей (шрифт Manrope — с Google Fonts, без сети берётся системный).

- Открыть локально: двойной клик по `index.html` или `python -m http.server` в этой папке.
- Ссылка на установку: константа `DOWNLOAD_URL` в начале `script.js`. Пока она пустая, главная кнопка показывает «Скоро».
- Цифры и возможности на странице взяты из кода приложения (справочник упражнений, программы, база продуктов, рационы, программы восстановления). При изменениях в приложении — обновить блок `numbers` и карточки `features` в `index.html`.
- После правки `styles.css` или `script.js` увеличить номер `?v=` в ссылках на них в `index.html`: GitHub Pages разрешает браузеру 10 минут держать файлы в кэше, и без этого новая страница может открыться со старыми стилями.
